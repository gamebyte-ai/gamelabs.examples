# Brick Breaker

A gamelabs.js playable-ad scaffold. Boots a single HUD screen with the title +
tap-to-start prompt; paddle / ball / bricks gameplay is layered on step by step.

## Develop

```bash
npm install
npm run dev      # vite dev server (port 5193)
npm run typecheck
npm run build
```

Or from the repo root: `./RunBrickBreaker.sh`.
